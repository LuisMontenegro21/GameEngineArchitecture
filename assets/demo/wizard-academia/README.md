# Wizard Academia capture evidence

Add the manually captured submission media here:

- `training-scene.png` — day, actions, energy, attributes, activity selection,
  and feedback visible.
- `card-acquisition.png` — three generated cards, their category labels, and
  the collection panel visible.
- `completion.png` — the five-day completion screen and collected-card count.
- `wizard-academia-demo.gif` (or a short video) — one training decision, card
  acquisition, and transition to the next day.

Use the in-game keyboard controls documented in the root README. Capture media
from a local LOVE run; headless Lua tests cannot produce visual evidence.
